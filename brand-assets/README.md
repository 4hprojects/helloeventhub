# HelloEventHub Celebration Pine brand assets

Created for the HelloEventHub development package. Brand: Glacier Blue `#397FAF`, Sky Blue `#69A9D1`, Deep Blue `#205477`, Coral `#F28B78`, Amber `#F0BE62`.

## Files
- `logos/`: transparent scalable SVG and high-resolution PNG logo variants.
- `icons/`: favicon, square PWA sizes, and maskable icon.
- `graphics/`: event default banner (SVG/WebP), social preview (SVG/PNG), confirmation illustration, email header.

## Usage
Use `logos/logo-horizontal.svg` in navigation, `logos/logo-stacked.svg` for large placements, and `logos/logo-symbol.svg` where a compact logo is needed. Use `icons/icon-192.png`, `icons/icon-512.png`, and `icons/icon-maskable-512.png` in the PWA manifest. Supply per-event banners where available and fall back to `graphics/default-event-banner.webp`.

SVG files contain vector geometry, with system font fallbacks for the wordmark. If exact font rendering is required, convert wordmark text to outlined paths during final brand approval. The logo is an initial original vector interpretation of the selected Celebration Pine concept, and should receive visual approval and similarity review before a commercial launch. The square icons and banners are exported assets, not independent AI image crops.
